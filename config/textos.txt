#  Como mudar:
#   1. Troque só o que está DEPOIS do "=". Não mude o nome antes do "=".
#   2. {palavra} entre chaves é preenchida pelo bot (ex.: {titulo} vira o nome
#      da sessão). Pode tirar ou mudar de lugar, mas não invente novas.

#   4. Publique com: npm.cmd run deploy  (os testes avisam se algo quebrou)
#  Limites do Discord: botões até 80 letras; descrições de comando até 100.
